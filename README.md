# Rhino Context Assist 1.0.3

Vollständiges Rhino-8-Projekt mit dynamischer Toolbar, deutscher Oberfläche, Optionen, Favoriten, Statistik, automatischer Priorisierung, Mesh-/SubD-Unterobjekten und Blockfunktionen.

Neu: Inset für Flächen, Extrudieren und schließen, Rohr für geschlossene planare Kurven, Zerlegen und coplanare Flächen vereinigen für Flächenverbände, sowie weltachsenorientierte Linien-Hüllkörper über BoundingBox/Curves.

## GitHub Build
Inhalt dieses Ordners in die Repository-Wurzel hochladen. Unter Actions den Workflow starten. Artefakt `RhinoContextAssist-1.0.3` herunterladen und die RHP installieren.
